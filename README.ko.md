# Agmet Slity

[English](README.md)

**Run the team you need, not the team you configured.**

Agmet Slity는 멀티에이전트 협업의 실제 효율을 측정하기 위한 오픈소스 개발자 도구의 가칭입니다. 검증된 작업 품질을 유지하면서 중복 탐색, 불필요한 위임, 대기와 재시도를 줄이는 것이 목표입니다.

## 현재 상태

**최소 문서를 준비하는 0.1 단계입니다.** 설치 가능한 앱, CLI, 수집기, 보고서 생성기, 데스크톱 UI와 자동 테스트는 아직 없습니다. CI는 0.4 단계에서 구축합니다. 현재 문서는 모델을 호출하지 않습니다.

초기 대상 환경은 Windows 11, WSL2 Ubuntu, Codex CLI입니다. 실제 지원 여부는 아직 검증하지 않았습니다. WSL 없는 Windows, Linux, macOS는 향후 대상입니다.

프로젝트명은 가칭입니다. Google이나 OpenAI의 공식 제품이 아닌 독립 프로젝트입니다.

## 측정하려는 내용

- 여러 에이전트의 동일 파일·문서·명령 반복 탐색
- 작업 위임, 메시지 전달, 유휴 시간, 실패와 재시도
- 코드 변경에 대한 실제 검증 근거의 유무
- 요청한 모델 설정과 실행 중 관측한 증거의 차이
- 비교 가능한 팀 구성별 품질, 실행 시간, 관측된 사용량

모두 계획 중인 기능이며 구현이나 개선 효과를 입증한 상태가 아닙니다. 에이전트 수가 적다는 사실만으로 성공을 판단하지 않습니다. 기존 도구와의 중복·차별화는 0.2 단계에서 확인해야 하며, 재현 가능한 성능 측정 결과도 아직 없습니다.

## 데이터와 개인정보

첫 수집기는 모델 호출 없이 기존 로컬 Codex 실행 기록을 가져오는 방식으로 계획하고 있습니다. 출처와 불확실성을 보존하며, 사용량이 없으면 0이 아닌 `unknown`으로 남깁니다. 분석에서는 확인된 관측, 비효율 의심, 판단 정보 부족을 구분합니다.

현재는 로그를 수집하지 않습니다. 향후 공개 예제에는 합성 기록을 사용합니다. 인증 파일, 비밀 정보, 개인 대화와 원본 실행 로그를 Issue나 PR에 첨부하지 마세요. [보안 지침](SECURITY.md)을 확인하세요.

## 시작하기

현재 설치하거나 실행할 프로그램은 없습니다. [기여 절차](CONTRIBUTING.md)와 [에이전트 작업 지침](AGENTS.md)부터 확인하세요. 수집기와 보고서 기능이 구현되면 모델 호출이 필요 없는 짧은 데모 명령을 안내합니다. 스크린샷은 실제 UI가 준비된 뒤 추가합니다.

## 로드맵

각 세부 단계는 별도의 명시적 요청으로 진행합니다. 한 단계의 완료는 다음 단계의 실행을 허용하지 않습니다.

| 단계 | 예정 산출물 |
| --- | --- |
| 0.1 | 공개 저장소와 최소 프로젝트 문서; 이번 범위 |
| 0.2 | 독립적인 선행 조사와 차별화 가설 검증 |
| 0.3 | 코어/UI 분리, 증거 모델과 아키텍처 결정 |
| 0.4 | 개발 도구, Issue/PR 템플릿과 CI |
| 1 | 모델 호출 없는 가져오기, 정규화, 스레드 연결과 JSON 내보내기 |
| 2 | 근거가 포함된 JSON·HTML 효율 보고서 |
| 3 | 명시적인 팀 선택과 이유를 설명하는 규칙 기반 추천 |
| 4 | 품질·시간·관측 사용량을 비교하는 재현 가능한 실험 |
| 5 | 검증된 코어를 사용하는 데스크톱 앱 |
| 6 | 선택적 Harness² 어댑터와 별도의 개선 실험 |
